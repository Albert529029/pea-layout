1

背景

公众号排版有三道老难题，模板解决不了：

  • 千篇一律——秀米高级模板好看，但人人都用，读者一眼认出"又是那个模板"。
  • 风格不贴内容——科技文套了花哨卡通风，情感文用了冷硬工业风，气质对不上就掉价。
  • 原创装饰门槛高——想要一支手绘枝叶、一方水墨印章，要么找设计师，要么不会画。

pea-排版糕手 的思路：把"资深视觉设计师 + 前端工程师"装进一个技能里。先读文章定风格，再用纯 CSS + 内联 SVG 手写装饰，每篇都不重样，且全部 inline-style，直接进微信/秀米就能用。

2

能做什么

内容感知设计

通读全文，提取文章类型、情感基调、核心意象、目标读者、内容结构，据此推导最匹配的视觉风格——不套固定模板。

代码绘制装饰

用纯 CSS + 内联 SVG 画植物、水墨、几何、插画类装饰，每篇完全原创，不是色块线条堆砌。

风格差异化

色相轮偏移、装饰换母题、布局变结构、编号系统唯一化，连排两篇同类型也必须明显不同。

微信兼容 + 三形态交付

所有样式 inline，100% 兼容秀米/微信编辑器。一次产出预览 HTML、源码 Markdown、手机长图，交付即闭环。

玩法

①

②
指定风格
想走某方向，说一声就按它来
③
要求修改
哪不满意说哪，整体不破
④
迭代收尾
长文贯穿同风格，图位自动占位

长文中途不换风格；文章有图时用 <!-- 此处插入图片 --> 占位并配说明框。

它是怎么做出来的

技能由「主定义 + 4 份参考 + 示例与脚本」构成，分层解耦、可独立维护：

pea-layout/
├── SKILL.md                 主定义：角色 / 工作流程 / 技术规范 / 红线
├── references/
│   ├── style-library.md       8 套风格库 + 内容→风格映射 + 差异化策略
│   ├── decoration-library.md  9 个可复用 inline SVG/CSS 装饰组件
│   ├── output-spec.md         骨架模板 + 字号颜色规范 + 质检清单
│   └── delivery-workflow.md   三形态交付 + 长图渲染说明
└── assets/
    ├── examples/
    │   ├── 苹果治愈文-公众号排版.html
    │   └── 长安烟火文-公众号排版.html
    └── render_longimage.py   Playwright 长图渲染脚本

关键约束写在 SKILL.md 的「技术规范」里：只用 <section>、全部 inline style、禁用 class/id/JS/外链、SVG 内联且属性写元素上、并排布局用 <table>。装饰库和输出规范保证每次产出都稳定过微信渲染。

6

怎么用

触发词：排版 / 公众号排版 / 微信排版 / 文章美化 / 秀米格式 / 推文排版 / 文章视觉设计。

四步出稿：

  • 说需求——"帮我把这篇公众号文章排个版"，或指定风格（如"走新中式水墨风"）。
  • 收三形态——预览 HTML（浏览器看效果）、源码 Markdown（含可复制 html 块）、效果长图 PNG（390px 手机整页）。
  • 复制进微信/秀米——把源码 Markdown 里 ```html 代码块整段复制，粘贴进编辑器正文即可，样式 100% 保留。
  • 反馈迭代——"徽章换圆形""主色再暖一点"，它按反馈微调且保持整体设计完整。

长图由无头浏览器按 390px 宽、2x 缩放整页渲染，是真实截图，非占位图。需要批量排版时，可逐篇调用，差异化策略确保篇篇不同。
