## 三、差异化保障策略（红线级要求）

同一作者连续排版极易雷同。**每篇必须至少触发以下 5 条中的 3 条**，且在内部思考中记录「与上一篇的区分点」：

1. **色相轮偏移**：即便同选暖色系，也通过旋转主色相（±20°~40°）制造差异，避免两次用同一组 HEX。
2. **装饰图案更换**：装饰母题必须换（上篇用枝叶→本篇用水墨/几何/食物插画），不可复用同一 SVG path。
3. **布局结构变化**：圆角卡片 ↔ 直角留白、单栏 ↔ 双栏 table、疏朗 ↔ 紧凑，至少一项不同。
4. **编号系统唯一化**：数字徽章 / 汉字印章 / 爱心序号 / 金线序号，四选一且不与上一篇重复。
5. **分隔线原创**：每篇分隔线图案（叶枝 / 笔触 / 波浪 / 几何 / 故障）必须新画，禁止复制上篇。

**记录格式（内部，不输出）**：`上一篇用了[X风格+Y装饰+Z编号]，本篇改用[A风格+B装饰+C编号]，区分度成立。`
