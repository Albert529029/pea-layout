# pea-公众号排版糕手（pea-layout）

一个 WorkBuddy 技能：把「视觉设计师 + 前端工程师」装进工作流，为微信公众号文章做内容感知的排版设计，并一次性产出三形态成稿。

## 它能做什么

- **内容感知设计**：通读全文，判断文章类型、情感基调、核心意象、目标读者与结构，推导最匹配的视觉风格，不套模板。
- **代码绘制装饰**：纯 CSS + 内联 SVG 手绘植物、水墨、几何、插画类装饰，每篇原创，不是色块线条堆砌。
- **风格差异化**：色相偏移、装饰换母题、布局变结构、编号系统唯一化，连排同类型也必须明显不同。
- **微信 / 秀米 100% 兼容**：全部 inline style，粘贴即用。
- **三形态交付**：预览 HTML + 可复制源码 + 手机长图，交付即闭环。

## 快速使用

触发词：排版 / 公众号排版 / 微信排版 / 文章美化 / 秀米格式 / 推文排版 / 文章视觉设计。

把本目录放入 WorkBuddy 的 `skills/` 目录（用户级或项目级），对话中说「帮我校排这篇公众号文章」即可。技能返回三份文件：

1. `{主题}-公众号排版-预览.html` —— 浏览器双击直接看效果
2. `{主题}-公众号排版-源码.md` —— 内含可整段复制的 html 代码块，粘进微信 / 秀米
3. `{主题}-公众号排版-效果长图.png` —— 390px 手机宽度整页渲染的真实长图（非占位图）

## 目录结构

```
pea-layout/
├── SKILL.md                  主定义：角色 / 流程 / 技术规范 / 红线
├── references/
│   ├── style-library.md      8 套风格库 + 内容映射 + 差异化策略
│   ├── decoration-library.md 9 个可复用 inline SVG/CSS 装饰组件
│   ├── output-spec.md        骨架模板 + 字号颜色规范 + 质检清单
│   └── delivery-workflow.md  三形态交付 + 长图渲染说明
└── assets/
    ├── examples/             两个完整范本（暖光治愈 / 新中式水墨），含 HTML + PNG 预览图
    └── render_longimage.py   Playwright 长图渲染脚本
```

## 长图渲染

`assets/render_longimage.py` 用 Playwright 按 390px 宽、2x 缩放、整页截图：

```bash
pip install playwright && playwright install chromium
python assets/render_longimage.py 预览.html 效果长图.png
```

## 技术规范（红线）

- 仅用 `<section>` 容器，全部 inline style
- 禁用 class / id / JavaScript / 外链资源
- SVG 内联，属性写在元素上
- 并排布局用 `<table>`
- 每篇至少 3 种不同类型装饰，且含 SVG 插画
- 两次排版不得使用完全相同的色彩方案与装饰图案
